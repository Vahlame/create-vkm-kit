# Live inspiration — steal from the world, not from this skill

The anti-generic engine in `direction.md` bans the model's _first_ default. Field failure:
agents then sample **this skill's own menus** (`lineages.md` capsules, `contemporary.md`
moves, the worked example's look) and every cloud model, local model, Cursor session and
keyboard-driven pass ships the same second template — Fraunces on warm paper, or dark-luxe
gold, or a grain overlay plus a giant cropped wordmark. Closed menus become the new Inter.

This file exists so Surface-tier work looks at **the live web (or a real artifact) for THIS
brief** before any direction is named. The dossier is a gate, not a mood-board.

## Why memory-precedents fail

Naming "Josef Müller-Brockmann" from training data and then shipping Inter is not research.
Vibe-coding write-ups in 2025–2026 (and arXiv:2603.13036 on design homogenization) describe
the same mechanism: models emit the training-set median; a skill that only _prices_ indigo
still emits the median of whatever is left. The fix is **external evidence for this job**,
not a longer forbidden list.

## The dossier (gate)

Before `direction.md`, show the user three lines (Surface tier, generate mode):

```text
Stolen from live (this brief only):
1. <url> — steal: <one technique> · space: <how they pad/group> · reject: <what not to copy>
2. <url> — steal: … · space: … · reject: …
3. <url> — steal: … · space: … · reject: …
Banned default: <the autopilot sentence you will not ship>
```

Rules:

- Three URLs (or photographed/printed artifacts with a source you can name) that do **this
  brief's job**, not "nice websites".
- The three must differ in at least two of: layout topology, material, type energy, motion
  technology. Three editorial serif homepages is one precedent, repeated.
- Each "steal" is a **technique** (how type is cropped, how a table is the page, which CSS
  or canvas method makes the light, how a card's padding relates to the type) — not an
  adjective ("bold", "premium", "minimal").
- Each "space" names a measured attitude: tight instrument / gallery air / print measure /
  overlapping editorial. You will copy that attitude into tokens, then `ui-audit` will check
  the render.
- Direction axes later must cite which dossier line they came from. An axis with no parent
  in the dossier is noise — cut it.

## How to search (so you don't all land on the same three Awwwards)

Do **not** query "best websites 2026", "awwwards", or "award-winning hero". Those queries
converge every agent on the same ten tropes.

Query the **job + medium + a constraint**: "bike shop POS dense status UI", "field-guide
species layout print", "hardware checkout terminal typography", "wedding stationery web
not template". Fetch the pages (obscura / web). Open them. Write the steal from what is
on the page, not from the title.

If a live page uses a visual technology you don't have in muscle memory (scroll-driven
CSS, mix-blend, SVG filter, canvas grain, view transitions, subgrid, a custom shader),
look up the **current** how-to at use-time — `craft-tech.md` (this folder) is a decoder
of categories, not a menu to order from.

## What to steal

From each page, extract at most:

1. **Topology** — where the eye lands, what is a column vs a filmstrip vs a table.
2. **Material** — paper, metal, phosphor, ink, product photography, nothing-but-type.
3. **Spacing attitude** — gutter from the glass, air inside components, gap between groups
   vs within a group (this is what `vkm-ui-judge` will measure later).
4. **One implementation trick** — a real CSS/SVG/canvas/motion method visible on that page.

Do not steal their logo, their copy, or their whole palette unless the brief is a redesign
of that product.

## Hard bans

- Copying a capsule in `lineages.md` (type list + OKLCH seeds) as the look. Capsules are
  _grammar_ (density, shape, motion personality). Type and colour come from the dossier
  or from `palette.mjs` seeded by a hue you can justify from a live page.
- Copying the worked example's POS instrument, or any skill screenshot, as an aesthetic.
- Picking 1–2 moves from `contemporary.md` because they are in the file. That file decodes
  what you _see_ on live pages; ordering from it is how consecutive builds rhyme.
- Reusing your last session's dossier on an unrelated brief.
- Invented URLs, invented awards, "a site I remember". No live lookup → the degradation
  ladder below, never a fake dossier.

## Degradation

No web access → write `NO LIVE LOOKUP` in the dossier slot, name three **physical**
precedents (a printed specimen, a machine, packaging, a film still) with why each works
for this job, and you still may not copy skill capsules as costume. Library versions stay
marked unverified. The visual loop and `ui-audit` still run if a renderer exists — spacing
does not need the internet.
