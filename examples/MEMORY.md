# MEMORY

## Uso del vault

- Referencia **opcional** — consulta si aporta contexto; no debe sesgar al agente.
- Sin preferencias personales, licencias, keys ni datos sensibles.
- Bugs verificados → `KNOWN_FAILURES.md`.
- Guardar solo lo reutilizable y solo con confirmación del usuario.

## Reglas de memoria

- Separar hechos de hipótesis.
- No guardar TODOs del día ni salida de comandos.
